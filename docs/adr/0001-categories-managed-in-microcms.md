# Category の正本は microCMS に置く

Category（学習分野の分類）はコードの固定セットではなく microCMS のコンテンツとして管理し、
アプリは取得して表示するだけにする。分類は6個で安定しているためコード定数（型安全・ルーティングがクリーン）
も有力だったが、運営者がデプロイなしでカテゴリの追加・編集（名前・説明・アイコン）を行えることを優先した。

## Consequences

- microCMS に category スキーマ（name / slug / 説明 / アイコン）が必要。
- トップページ Output セクションのアイコン・説明文のハードコード（page.tsx）を、取得した Category 駆動に置き換える必要がある。
- カテゴリ一覧・カテゴリ別ページの URL は slug 駆動になる。
