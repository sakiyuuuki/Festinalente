# ビジュアルデザイン言語: 端正なアイデンティティ × モダンな技術ブログ

Festina Lente（ゆっくり急げ）の穏やかで端正な世界観を残しつつ、長文＋コードを快適に読める
モダンな技術ブログとして再設計する。具体的には:

- **タイポgraf:** 見出し・ロゴは明朝体（Zen Old Mincho）で世界観を担い、本文・UI はゴシック
  （Inter + Noto Sans JP）で可読性を確保、コードは monospace。すべて `next/font` でホストする。
- **配色:** プライマリアクセントをインディゴ（#4f46e5 / hover #4338ca）に刷新。
  旧来の緑・テラコッタは退ける。ニュートラルはグレースケール。
- **トークン化:** 色・余白・タイポスケールを CSS カスタムプロパティに集約し、各 CSS Module から参照する。

## なぜ

全面明朝は世界観は最大だが長文・コード近傍で可読性が落ち、全面ゴシックは読みやすいが識別性が弱い。
見出し＝明朝／本文＝ゴシックの使い分けで両立させた。アクセントは既存の緑/テラコッタの役割が
混在していたため、規律ある単一アクセント（インディゴ）に刷新した。

## Consequences

- `next/font` 導入で globals.css のフォント指定を置き換え（現状 Zen Old Mincho は未読み込みのフォールバック状態）。
- 各 CSS Module に直書きされた色（#2cb67d, #da9168 等）をトークン参照へ移行する。
