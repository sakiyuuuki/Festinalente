# 元の明朝フォントと緑＋テラコッタ配色を維持する（ADR-0004 の一部を撤回）

運営者の希望により、[ADR-0004](./0004-visual-design-language.md) で決めた
「インディゴ単一アクセント」「明朝見出し×ゴシック本文」を撤回し、**元サイトの見た目**に戻す:

- **タイポグラフィ:** サイト全体を Zen Old Mincho（明朝）にする（本文・UIもゴシックではなく明朝）。
  コードブロックのみ monospace のまま。すべて `next/font` でホスト。
- **配色:** プライマリアクセント＝緑 `#2cb67d`（リンク・区切り線・タグ）、CTA＝テラコッタ `#da9168`
  （「もっと見る」等の主要ボタン）。インディゴは廃止。

## なぜ

Phase 3a 完了後のプレビューを運営者が確認し、元サイトの落ち着いた明朝＋和の配色（緑／テラコッタ）を
そのまま活かしたいと判断したため。モダン化はレイアウト・レスポンシブ・トークン化で担保し、
色とフォントは元の世界観を維持する方針に切り替える。

## Status

ADR-0004 の「配色（インディゴ）」「フォント使い分け（明朝×ゴシック）」を supersede する。
ADR-0004 のその他（トークン化・next/font 導入・レイアウトのモダン化方針）は引き続き有効。

## Consequences

- globals.css の `body` フォントを `var(--font-mincho)` に、トークン `--color-primary` を緑へ、
  CTA 用トークン `--color-cta` を新設（[design-tokens.md](../design-tokens.md) 参照）。
- Phase 2/3a で `var(--color-primary)` を使った新規 CSS（記事・TOC・カテゴリ）は自動的に緑になる。
- Inter / Noto Sans JP は本文用途では不要になる（読み込みを外すか、フォールバックとしてのみ残す）。
